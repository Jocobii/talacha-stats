# CLAUDE.md

**La fuente de verdad de este proyecto es [`AGENTS.md`](./AGENTS.md).**

Toda guía de trabajo —posicionamiento del producto, arquitectura (FSD), reglas de
calidad de código, base de datos, normalización, seguridad, migraciones, módulos y
convenciones— vive en `AGENTS.md` y aplica por igual a cualquier agente (Claude,
Copilot, Cursor, etc.) y a devs humanos.

Este archivo solo importa `AGENTS.md` (línea 1) para que Claude lo cargue
automáticamente. No dupliques reglas aquí: si algo cambia, edítalo en `AGENTS.md`.
